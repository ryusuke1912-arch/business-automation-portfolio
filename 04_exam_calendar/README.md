# 入試カレンダー（小6・中3・高3）

受験生に入試日程を書いてもらい、教室に貼るカレンダーにまとめるための一式です。

## 流れ

1. **記入用紙を配る** … `入試日程_記入用紙.docx` を人数分印刷（A4・1人1枚）
   - 名字を印字したい場合は `names.csv`（`学年,名字` を1行1人）を作って
     `node make_form.js names.csv` → `入試日程_記入用紙_名前入り.docx`（1人1ページ）
2. **回収した内容を入力** … `入試日程_サンプル.csv` と同じ形で `入試日程.csv` を作る
   （列：日付,学年,名字,学校名,区分。日付は `1/16` だけでも可）
3. **カレンダーを作る** … `python make_calendar.py 入試日程.csv`
   → `入試カレンダー.xlsx`（2026年12月〜2027年3月を各月A4横1枚＋日付順の一覧）
   - 手書き用の空欄カレンダーは `入試カレンダー_空欄.xlsx`

## 収録ファイル

| ファイル | 内容 |
|---|---|
| 入試日程_記入用紙.docx | 生徒配布用の受験校記入用紙（学校名＋推薦・一般に○。日付は教室で調査） |
| 入試カレンダー_空欄.xlsx | 手書き用カレンダー |
| 入試カレンダー_サンプル.xlsx | 架空データで自動記入した見本 |
| make_form.js / make_calendar.py | 作成スクリプト |

> サンプルの名字・日程は架空です。実際の生徒名を含むファイル（names.csv、入試日程.csv、
> 入試カレンダー.xlsx、名前入り用紙）は `.gitignore` 済みで、コミットされません。
