# ミーティング用紙 縦1枚変換（mt_sheet.html）

A4横で作っているミーティング用紙（.xlsx）を読み込むと、**B5縦またはA4縦**の1枚にきれいに並べ替えて印刷できるHTMLです。

## 使い方（教室のPC）
1. `mt_sheet.html` を USB やメールで教室のPCにコピーする（このファイル1つだけでOK）
2. ダブルクリックして **Google Chrome または Microsoft Edge** で開く
3. その日のミーティング用紙（.xlsx）をドラッグ＆ドロップ、または「📂 Excelを選ぶ」
4. 画面上部の「用紙」で **B5縦／A4縦** を選ぶ（前回の選択を記憶）
5. 「🖨 印刷」→ 印刷画面の用紙サイズを同じもの（B5なら「B5 (JIS)」）にして印刷
   - 両面印刷にすると裏面に受験生カレンダーが入ります

## 特徴
- **ネット接続不要・インストール不要**（外部ライブラリを使わず、ブラウザだけでExcelを読む）
- ファイルはPCの外に送信されない
- セル位置の決め打ちではなく「立礼担当」「共有事項」「定期テスト」などの見出しから読み取るので、行が増減しても崩れにくい
- 伝達事項の数・文章量に合わせて文字サイズを自動調整し、必ず選んだ用紙の縦1枚に収める（手動調整も可）
- 赤字・部分的な赤字はそのまま再現
- 日付は今日の日付（変更可）。用紙上の文字はクリックして印刷前に直接修正できる

## 注意
- Excel内の月カレンダー図はEMF形式でブラウザ表示できないため、同じ月のカレンダーを自動作成して表示します（日曜・祝日は赤）。
- 動作確認：Chrome / Edge（2022年以降のバージョン）
