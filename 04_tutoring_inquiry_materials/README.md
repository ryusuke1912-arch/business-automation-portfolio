# 04. 資料請求対応：郵送資料・メール文面（個別指導塾）

問い合わせフォーム（電話不可・メール可・郵送資料希望）への対応一式。

## 成果物

- `メール文面.txt` — 先行して送るメール（郵送より早く届き、9月体験の期限に間に合う）
- `ご案内資料.docx` — 郵送用 A4 5ページ
- `generate_docx.js` — docx (npm) による生成スクリプト。`npm i docx && node generate_docx.js`

## 書式（社内標準に準拠）

- A4／余白 上下左右 2cm
- 本文 游明朝 10.5pt、字下げ 200、行間 1.14
- タイトル 游ゴシック太字 15pt・中央・#2E74B5
- サブタイトル 10pt・中央・#595959
- 見出し `◆ ○○` 游ゴシック太字 12pt・背景 #DEEAF6
- 箇条書きは `・` を直接入力（自動箇条書きは使わない）
- **「。」の次で改行**（「、」では改行しない。1文1行で読みやすさを保つ）

## 形式選定の考え方（ワード vs スライド）

電話拒否を明言する保護者は売り込みへの警戒が強く、検討の主導権を手放さない読み比べ型。
スライド調の資料は郵送物では広告・大量営業の印象を与えるため、
手紙・読み物形式のワードを採用。

## 構成上の設計ポイント

1. 冒頭で「電話は一切しない・連絡はメールのみ」を明言（相手の最重要関心事に最初に応える）
2. 現在通っている教室を貶めず、長所承認 → 構造的限界の順で説明
3. 体験当日に入塾を決めさせない方針を明記
4. 9月体験→10月入塾の目安と、コピペで使える申込テンプレートで行動コストを最小化
5. 「合わなければお読み捨てください」で撤退の自由を保証

## 使い方

【塾名】【教室名】【教室長名】【住所】【メールアドレス】を置換し、料金表を同封して郵送する。
