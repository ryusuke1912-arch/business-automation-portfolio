# 04. 資料請求対応：郵送資料ジェネレータ（個別指導塾）

問い合わせフォーム（電話不可・メール可・郵送資料希望）への郵送資料一式を Word (.docx) で自動生成するプロジェクト。

## 成果物

- `資料送付_送付状・ご案内資料.docx` — A4 全8ページ（送付状2P＋ご案内資料6P）
- `generate_mailer_docx.js` — docx (npm) による生成スクリプト。`npm i docx && node generate_mailer_docx.js`

## 形式選定の考え方（ワード vs スライド）

- 電話拒否を明言する保護者は「売り込まれること」への警戒が強く、検討の主導権を手放さない読み比べ型
- スライド調の資料は郵送物では広告・大量営業の印象を与えるリスクがある
- 手紙形式（送付状）＋読み物形式の本資料が誠実さを伝え、最も刺さると判断しワードを採用

## 構成上の設計ポイント

1. 送付状冒頭で「電話は一切しない・連絡はメールのみ」を明文で約束（相手の最重要関心事に最初に応える）
2. 現在の教室（自学自習型）を貶めず、長所承認→構造的限界の順で説明
3. 体験当日に入塾を決めさせない方針を明記し、心理的安全性を担保
4. 9月体験→10月入塾のモデルスケジュールとコピペで使える申込テンプレートで、行動コストを最小化

## 使い方

【塾名】【教室名】【教室長名】【住所】【メールアドレス】のプレースホルダを実際の情報に置換し、料金表を同封して郵送する。
