# 個別指導・シフト自動配置ツール

講師の出勤可否と生徒個別の受講不可枠を満たしながら、期間内の授業コマを自動で組むツールです。
**Excel本体は不要**（Python + openpyxl のみで .xlsx を直接読み書きします）。

> 本リポジトリの氏名・出勤表・受講データは、動作確認用に自動生成した**架空のサンプル**です。

---

## 何が問題だったか

学習塾の講習期間の時間割は、手作業だと1回あたり十数時間かかります。理由は、
単に「空いている枠に入れる」だけでは終わらないからです。

| 制約 | 内容 |
|---|---|
| 講師の出勤 | 日付×時間ブロック単位で出勤可否が違う（昼型／夜型の講師がいる） |
| 生徒のNG枠 | 「毎日13:00不可」「月曜終日不可」「火曜17:00以降不可」「8/1だけ不可」など個別 |
| 1日の上限 | 生徒ごとに1日あたり最大2〜3コマ |
| 席の定員 | 1講師が同時に見られるのは2名まで（1対2） |

さらに、現場としては次の2つを**同時に**満たしたい。

1. **1対2率を上げる** … 講師1人に生徒2人が付いた状態を増やす（人件費効率）
2. **生徒の空きコマを作らない** … 14:30と18:30だけ、のような穴あきは拘束時間が伸びて苦情になる

この2つは真っ向から衝突します。1対2を優先すると生徒の時間がバラけ、
連続性を優先すると席が埋まりません。**手作業ではどちらかを諦めることになります。**

---

## アプローチ

制約充足問題として解いたうえで、配置後に局所改善パスをかけて両立させます。

### 1. MRV法による処理順の決定
「生徒×科目」ごとに、出勤とNGを満たす枠が物理的に何個あるかを数え、
`余裕(slack) = 置ける枠数 − 必要コマ数` が小さいものから処理します。
制約の厳しい生徒を先に通すことで、後半に詰まって破綻するのを防ぎます。

### 2. 複合スコアによる貪欲配置
各コマを、次の優先順位でスコアが最大の枠に置きます。

```
(連続かつ1対2, 連続, 1対2, 既存コマに隣接, 同じ日に寄せる, 負荷分散, 日付が早い)
```

### 3. 改善パスA — 1対2への統合 (`pair_pass`)
1対1になっている枠を探し、同じ講師の別の1対1枠へ寄せて2人にまとめます。
移動先でも全制約（NG・上限・連続性・出勤）を満たす場合のみ実行します。

### 4. 改善パスB — 空きコマ解消 (`gap_pass`)
生徒の1日の並びが非連続になっている箇所を検出し、同日内で穴を埋める向きに移動します。
**このとき1対2を壊す移動は行いません**（`dst_pair - src_pair < 0` で棄却）。

### 5. A → B → A を再実行して収束

## 実行結果（サンプルデータ・14日間／講師8名／生徒14名／154コマ）

```
必要コマ数                       : 154
配置できたコマ数                 : 154
充足率                           : 100.0%
1対2率（相方がいるコマの割合）   : 85.7%
生徒の空きコマが出た「日」の数   : 0
講師の座席稼働率                 : 26.8%
改善パス（1対2統合／空きコマ解消）: 4件 / 0件
```

条件が厳しすぎて物理的に入りきらない科目がある場合は、諦めるのではなく
**「誰の何の科目が何コマ不足したか」を明示**します（`★不足`）。
運用側は「NGを緩める／担当講師を追加する／回数を減らす」のどれで対応するかを判断できます。

## 使い方

```bash
pip install openpyxl
python make_demo_data.py    # サンプル入力を生成（teachers.csv / students.csv / dates.csv）
python placer.py            # → schedule_out.xlsx
```

## 入力フォーマット

### students.csv
| 列 | 例 | 意味 |
|---|---|---|
| 生徒名 | 石田 陽菜 | 1行＝生徒×科目 |
| 学年 | 中3 | |
| 科目 | 数学 | |
| 回数 | 6 | 期間内に入れるコマ数 |
| 担当(優先順;区切り) | 青木 涼;川口 千尋 | 左から優先して埋める |
| 配分(順/分散) | 順 | `順`=左優先 / `分散`=複数講師に均等 |
| 1日上限 | 2 | |
| NG | `土;火17:00以降;8/1` | 下記構文 |

**NG構文**（`;` 区切り）
- `13:00` … 毎日その枠
- `18:30以降` … 毎日 18:30 と 20:00
- `月` … 月曜終日
- `火17:00以降` … 火曜の17:00以降
- `8/1` … その日は終日 ／ `8/1 18:30` … その日のその枠のみ

### teachers.csv
1行＝講師×日付。出勤できる時間ブロックに `○`（空欄＝不可）。

## 出力

`schedule_out.xlsx`

- **サマリシート** … KPIと、生徒×科目ごとの「配置／必要／不足」一覧
- **生徒別シート** … 生徒ごとに「日付→時間」順で並べたコマ一覧（科目・講師・1対1／1対2）。生徒・保護者への日程連絡にそのまま使える
- **日付別シート** … 講師×時間ブロックの座席表。配置コマはオレンジ、講師が出勤していない枠はグレー

---

## 応用できる領域

このエンジンは学習塾に限らず、**「人 × 時間枠 × 個別制約 × 定員」**の構造を持つ配置業務に転用できます。

- 店舗・コールセンターのシフト作成
- 面談・診療・カウンセリングの予約割当
- 会議室／設備の割当
- 実習・研修のグループ分け

制約の種類（NG構文・定員・上限・優先度）は入力CSV側で表現しているため、
業種ごとの要件はコード改修ではなく設定で吸収できる設計にしています。
