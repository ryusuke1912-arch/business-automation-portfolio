# 振替授業・自動配置ツール

**すでに埋まっている時間割**に、欠席分の振替を後から差し込むツールです。
**Excel本体は不要**（Python + openpyxl のみで .xlsx を直接読み書きします）。

> 本リポジトリの氏名・出勤表・受講データは、動作確認用に自動生成した**架空のサンプル**です。

---

## 何が問題だったか

[①シフト自動配置ツール](../01_shift_placer/) が「空の時間割を組む」のに対して、
こちらは**もう動いている時間割を壊さずに、あとから差し込む**問題です。難しさの種類が違います。

前提として席はすでに大半が埋まっており、残った隙間は次の条件を**同時に**満たす必要があります。

| 制約 | 内容 |
|---|---|
| 座席定員 | 1講師1コマにつき2名まで。既存授業が先に埋めている |
| 講師の出勤 | 日付×コマ単位。出勤していない枠には入れられない |
| 生徒別条件 | 担当できる講師・曜日・時間帯・「このコマだけ」等が生徒ごとに違う |
| 時間の重複 | 80分枠と50分枠が混在し、区間として重なる組み合わせがある |
| 連続性 | 同じ日に授業があるなら、間を空けずに前後へ付ける |
| 週の通塾日 | 生徒によっては「週◯日まで」の上限がある |

条件が厳しいため、**全制約を満たす解が存在しない件が必ず出ます。**
このとき現場で本当に困るのは「入らなかった」ことではなく、
**どの条件を譲って入れたのかが分からないまま表が出てくる**ことです。

振替は保護者への連絡が伴います。「担当が変わった」「通常授業と離れたコマになった」を
把握しないまま連絡すると、当日になって発覚します。

---

## アプローチ

### 1. 区間ベースの重複判定

コマ名の一致ではなく `[開始, 終了)` の重なりで判定します。
`18:30-19:50` と `19:00-19:50`（映像授業）のような**包含関係を取りこぼさない**ためです。
コマ名だけで比較すると、この2つは別物として通ってしまいます。

### 2. MRV法による処理順の決定

各振替について「物理的に置ける枠が何通りあるか」を数え、少ない順に処理します。
制約の厳しい生徒を先に通すことで、後半に詰まって破綻するのを防ぎます。

### 3. 段階的緩和 ― 本ツールの中心

全制約で置けなかった件を、条件を**1つずつ**緩めて再試行します。

| 段階 | 緩める条件 | 意味 |
|---|---|---|
| 第1段 | なし | 全制約を満たす |
| 第2段 | 連続性 | 通常授業と離れた単独コマを許容する |
| 第3段 | 指定講師 | 科目の担当実績が高い代替講師へ回す |
| 第4段 | 座席共有 | 短時間授業を通常授業に続けて実施する |

重要なのは順番です。**現場にとって影響が小さい条件から譲ります。**
「担当が変わる」は保護者への説明が要りますが、「コマが離れる」は時間割上の話で済むため先に譲ります。

そして**譲った内容を1件ずつ記録して返します。** 出力Excelでは該当行をオレンジで塗り、
標準出力にも「※ 指定講師（◯◯）が空かず代替講師へ」と理由まで出します。
黙って条件を破ると事故になるので、緩和は必ず可視化する設計にしています。

### 4. 座席共有の扱い（第4段）

「17:00-17:40の40分授業を受けている生徒に、続けて17:40から振替を入れる」ケースです。
同じ席・同じ講師のまま時間を分け合うため、**座席カウントを増やしません**。

ただし無条件に許すと80分授業の二重取りになるので、
`その日そのコマで本人が使っている分数 + 振替の所要分 ≤ コマの長さ` を満たす場合のみ実行します。

### 5. 独立検算

配置後、エンジンとは**別経路**で全制約を検査し直します。
配置時のスコアやフラグを信用せず、出力データを読み直して照合するため、
ロジックの取り違え（緩和フラグの付け忘れ等）を検出できます。

```
座席定員 / 時間重複 / 講師の出勤 / 生徒別条件 / 期限 / 座席表の描画あふれ
```

最後の「描画あふれ」は、席数を超えた配置が**Excel出力時に黙って切り捨てられる**事故を防ぐためのものです。
実際、開発中にこれで1件の欠落を検出しました。

## 実行結果（サンプルデータ・16日間／講師8名／生徒16名／既存177コマ）

```
振替対象件数                    : 42
配置できた件数                  : 41
充足率                          : 97.6%
全制約を満たせた件数            : 33
条件を緩めた件数                : 8
未配置                          : 1
座席稼働率（振替後）            : 94.3%
検算エラー                      : 0

  全制約          :  33件 配置 / 残 9件
  連続性を緩和    :   3件 配置 / 残 6件
  指定講師を緩和  :   4件 配置 / 残 2件
  同一コマ内で接続:   1件 配置 / 残 1件
```

座席稼働率94.3%というほぼ満席の状態に、42件中41件を差し込んでいます。
緩和した8件は、それぞれ**何を譲ったか**が付いた状態で返ります。

```
△ 条件を緩めて配置した件（運用側の確認が必要）:
   小4 相原 陽菜 国語 → 2026-10-14(水) 17:00-18:20 桐山 一馬
      ※ 通常授業（17:00-18:20）に続けて同一講師で実施／17:40開始・40分
   中2 菊池 芽依 数学 → 2026-10-10(土) 18:30-19:50 大西 悠人
      ※ 同日の授業（13:00-14:20）とは離れたコマ
   ...
★ 物理的に入りきらなかった件（条件を緩めるか出勤を増やす必要あり）:
   小5 飯塚 蒼太 数学（欠席 2026-10-10 17:00-18:20）
```

入らなかった1件は隠さず返します。運用側は
「条件を緩める／出勤を増やす／欠席扱いにする」のどれで対応するかを判断できます。

## 使い方

```bash
pip install openpyxl
python make_demo_data.py    # サンプル入力を生成
python makeup_placer.py     # → makeup_out.xlsx
```

## 入力フォーマット

### makeups.csv — 振替対象
| 列 | 例 | 意味 |
|---|---|---|
| 学年 / 生徒名 / 科目 | 中2 / 菊池 芽依 / 数学 | |
| 欠席日 / 欠席コマ | 2026-10-10 / 17:00-18:20 | 振替元 |
| 所要分 | 40 | 空欄＝コマの長さいっぱい |
| 元担当 | 大西 悠人 | 同じ講師を継続できると加点 |
| 期限 | 2026-10-20 | この日までに入れる（空欄＝制限なし） |

### rules.csv — 生徒別の振替条件
| 列 | 例 | 意味 |
|---|---|---|
| OK講師 | `桐山 一馬;倉田 真理` | この講師のみ（空欄＝誰でも） |
| OK曜日 / NG曜日 | `月;水` / `土` | |
| OKコマ | `17:00-18:20` | このコマのみ |
| 最早時刻 / 最終時刻 | `18:30` / `20:00` | 開始時刻の下限・上限 |
| 週上限日数 | `3` | 週の通塾日数の上限 |

### slots.csv / shifts.csv / lessons.csv / config.csv

- **slots.csv** … コマ定義（区分・コマ名・開始・終了・枠種別）。**時間の重なりはここから計算**します
- **shifts.csv** … 1行＝講師×日付。出勤できるコマに `○`
- **lessons.csv** … 既存授業（＝先に埋まっている席）
- **config.csv** … 座席定員／連続とみなす間隔（分）／配置不可講師

---

## 出力

`makeup_out.xlsx`

- **サマリシート** … KPI、段階別の配置件数、全42件の配置一覧（緩和した件はオレンジ）
- **日付別シート** … 講師×コマの座席表

座席表の色分けは次のとおりです。

| 色 | 意味 |
|---|---|
| 🟩 緑 | 講師の出勤あり（配置可） |
| 🟥 赤 | 出勤なし（配置不可） |
| 🟨 黄 | 今回入れた振替 |

「空いている」と「そもそも出勤していない」を色で分けるのが要点です。
白紙のままだと、表を見た人が出勤していない枠に振替を入れてしまいます。

## 応用できる領域

**「稼働中のスケジュールに、個別条件つきの予定を後から差し込む」**構造を持つ業務に転用できます。

- 診療・整体・美容室の予約振替（担当者指名・営業時間・施術時間の混在）
- 会議室／設備の追加予約
- 保守・点検の再訪問日程の割当
- 研修の補講回

条件はすべて入力CSV側で表現しているため、業種ごとの要件はコード改修ではなく設定で吸収できます。
段階的緩和の**順番**（何から譲るか）も、現場の優先度に合わせて並べ替えるだけで変えられます。
