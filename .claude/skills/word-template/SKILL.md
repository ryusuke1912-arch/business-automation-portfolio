# 標準Word書式（教室長テンプレート）

Word文書を作るときは、このスキルの書式に必ず合わせる。
人が丁寧に作った日本のビジネス文書に見えることを最優先にする。

## 書式ルール（必須）

| 項目 | ルール |
|---|---|
| フォント | すべて **ＭＳ 明朝**。本文 **10.5pt**。表題のみ14pt太字、注記（※）は9pt |
| 色 | 文字はすべて黒。色は表の見出し行の薄いグレー（D9D9D9）と、左端列の極薄グレー（F2F2F2）だけ。カラーの帯・囲み・アイコン・絵文字は使わない |
| 改行 | **「。」の後は必ず改行**する。本文・箇条書き・表のセル・注記すべて |
| 用紙 | A4縦、上30mm・下25mm・左右22.5mm、行グリッドあり、ページ下中央に「- 1 -」 |
| 冒頭 | 右に日付 → 左に宛名（「〇〇 様」「保護者様」「講師 〇〇 先生」）→ 右に教室名・教室長 → 中央に表題 |
| 本文 | あいさつ文 → 「記」（中央）→ 項目 → 右寄せ「以上」で締める |
| 見出し | 「１．」（全角数字＋全角ピリオド、太字）→「（１）」（太字、1字下げ） |
| 箇条書き | 「・」で始め、2行目以降はぶら下げ。チェック項目は「□」 |
| 表 | 黒の細い罫線。見出し行は薄いグレーで中央揃え。数値列は中央揃え |
| 記入欄 | 空欄の行は高さを確保する。署名欄は「担当講師　＿＿＿＿＿＿」のように下線で |
| 数字 | 文章中の1桁の数字は全角（１、２）。2桁以上や点数・年号は半角（376点、2026年） |
| 文体 | 保護者・生徒向けは丁寧語（です・ます、～いたします）。社内向けは簡潔な「～してください」 |
| 表紙 | 原則つけない（1ページ目から宛名・表題で始める） |

## 作り方（Claude Code・コード実行環境）

`lib/jdoc.js` に部品がそろっている。`docx`（npm）が必要（入っていなければ `npm install docx`）。

```js
const J = require('<このスキルのフォルダ>/lib/jdoc.js');
J.save([
  ...J.letterHead({ date: '2026年10月21日', to: ['保護者様'], from: ['〇〇教室', '教室長　〇〇'] }),
  ...J.title('表題', 'サブタイトル（任意）'),
  J.blank(),
  J.body('あいさつ文。「。」ごとに自動で改行される。'),
  J.blank(),
  J.ki(),
  J.head('１．見出し'),
  J.sub('（１）小見出し'),
  J.body('本文。'),
  J.item('箇条書き。'),
  J.check('チェック項目'),
  J.table([2200, J.W - 2410], [['項目', '内容'], ['行見出し', '内容。']], { firstCol: true }),
  J.frame(['【所見】', '囲みの中の文。']),
  J.note('※ 注記。'),
  J.ijo(),
], '出力.docx');
```

- `table(widths, rows, opts)`：列幅の合計は `J.W - 210`（9144）以内。opts は `firstCol`（左端列を薄グレー）、`mid`（中央揃えにする列番号の配列）、`size`（文字サイズ、表が混む時だけ 20＝10pt や 18＝9pt）、`rowH`（記入欄の行の高さ、例 680）、`indent`（0 で左端まで使う）
- 改ページは `J.pageBreak()`
- 見本は `examples/sample.js`

## 仕上げの確認

1. PDFに変換して画像で確認する（docxスキルの手順：`soffice --headless --convert-to pdf` → `pdftoppm`）
2. 見出しだけがページ末尾に残っていないか、最終ページが注記や「以上」だけになっていないかを確認する。なっていれば記入欄の高さや空行で調整する
3. 確認環境にＭＳ明朝がない場合は代わりのフォントで表示される。レイアウト確認だけに使う
4. 生徒の個人情報を含む文書は、リポジトリにコミットしない
