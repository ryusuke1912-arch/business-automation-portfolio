## 1. ビカムキングはなぜC2で通用しなかったか

結論：クラスの壁ではなくペースの違い。速い上がりが使えない持続型で、11/11はスローの上がり勝負になった。

11/11の勝ち時計 1:32.7 は、ビカムキングのC3勝ち 1:32.4 より遅い。C2の馬が時計的に強かったわけではない。

| | 10/21 C3（1着） | 11/11 C2二（5着） |
|---|---|---|
| レース600m通過 | 38.1 | 40.1（2.0秒遅い） |
| レース上がり3F | 41.3 | 39.5 |
| ラスト1F | 14.5 | 13.9 |
| ビカムキングの800m通過（走破−上がり） | 51.6 | 53.2（1.6秒遅い） |
| ビカムキングの上がり3F | 40.8 | 40.4（0.4秒しか速くない） |
| 走破タイム | 1:32.4 | 1:33.6 |

- 10/21は消耗戦（2F目11.4、ラスト14.5）。全馬がバテる中、同じ脚を長く使えるこの馬が残った。
- 11/11は4角2〜3番手で位置は完璧。前半を1.6秒楽に走っても上がりは0.4秒しか縮まらなかった。上位4頭は上がり39.1〜39.6、この馬は40.4。着差0.9秒はすべて最後の3F。
- 仮説：この馬の上がり上限は40秒台前半。根拠は2走のみなので全走で要確認。

**消し条件の候補**：持ち時計は上位だが、上がり自己ベストがメンバー下位の先行馬 × スロー見込みのレース。
**買い条件の候補**：同じ馬でも前半が速くなりそうなメンバーなら時計どおり走れる。

## 2. 未対戦の馬同士の力関係を出す方法

**走破タイム（または補正9）＝ 馬の能力 ＋ レース固有の効果 ＋ 誤差**

- レース固有の効果（馬場差・ペース・距離）は同じレースの全馬が共有するので、レース内の着差だけが能力差として残る。
- 全レースを連立して一括で解く。AがBに0.5秒勝ち、BがCに0.3秒勝っていれば、A–Cは未対戦でも0.8秒差と推定できる。
- 推定の誤差幅も同時に出る。対戦のつながりが濃い馬同士ほど誤差が小さい。
- 投資基準：出走馬どうしの能力差の誤差幅が小さいレースだけ買う（「同日・同レースで一緒に走った回数が多いレースに絞る」発想の数学版）。

補正9との違い：基準タイムや馬場差を人が決めず、直接・間接対決だけから逆算する。クラスの壁は自動で織り込まれる。

## 3. 出馬表時点での即予想について

後から全頭に説明がつくことは、事前に当てられる証拠にならない（結果を知っていればどんな負けにも理由はつく）。

| 要素 | 事前にわかるか |
|---|---|
| 馬の型（持ち時計・上がり上限・持続型/瞬発型） | わかる |
| 脚質の構成（逃げ・先行馬の頭数） | わかる |
| 実際のペース | 傾向まで |
| 出遅れ・騎手判断・馬場変化 | わからない |

手順：
1. 馬ごとの型を数値で持つ（持ち時計、上がり自己ベスト、通過順の平均）
2. 出馬表からペースを3段階で見込む（前走で前半を速く行った馬の頭数）
3. ルールを先に固定する（例：スロー見込み × 人気の先行馬 × 上がり自己ベスト下位 → 消し）
4. レース前に決められる条件だけで過去データに当て、回収率で判定する

最初に確かめること：**出馬表から見込んだペースが実際どれだけ当たるか**。これがこの方法の上限を決める。

## 4. 検証計画（データ投入後）

| 検証 | 内容 |
|---|---|
| 基準値の比較 | 3か月最高値／良のみ最高値／やや重込み最高値／上位2走平均／直近値のどれが着順を最もよく当てるか |
| 格上頭数別の成績 | 補正9が自分より上の馬が0・1・2・3頭以上のときの勝率・連対率・複勝率 |
| 馬場別 | 良／やや重／重・不良で関係が崩れるか |
| 消し条件 | 1〜5番人気で格上が2頭以上いる馬の単勝・複勝回収率 |
| ペース型 | 上がり自己ベスト下位の人気先行馬 × スロー見込みの回収率 |
| 新モデル比較 | 一括推定が補正9より当たるか、誤差幅の小さいレースに絞ると回収率が上がるか |

注意：
- 最高値は出走回数が多い馬ほど高く出る。回数をそろえるか、上位2走平均と必ず比べる。
- 連対率の差だけでは利益にならない。判定は必ず回収率で行う。
