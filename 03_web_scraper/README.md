# Webスクレイピング → CSV / Excel 納品ツール

Webサイトから情報を収集し、そのまま業務で使える CSV / Excel にして納品するツールです。

**対象サイトについて**：デモの取得先は
[books.toscrape.com](https://books.toscrape.com/)（スクレイピング学習用に公開されている練習サイト）に固定しています。
実在のサービスへ無断でクローラを当てないためです。実案件では、対象サイトの
利用規約と robots.txt を事前に確認したうえで着手します。

---

## 「取れればいい」で終わらせない

スクレイピングは動かすだけなら30行で書けます。実務で問題になるのはその後です。

| よくある事故 | 本ツールの対策 |
|---|---|
| 相手サーバに負荷をかけ、アクセス遮断される | リクエスト間隔＋ゆらぎを入れて連続アクセスしない |
| 規約・robots.txt を確認していない | 起動時に robots.txt を取得し、許可されないURLは取得しない |
| 無記名のbotとして遮断される | User-Agent に用途と連絡先を明示 |
| 一時的な通信エラーで全部落ちる | 指数バックオフで3回再試行 |
| 1件失敗すると最初からやり直し | 取得済みHTMLをキャッシュし、途中から再開 |
| 何件取れたか分からないまま納品 | 件数・欠損・重複を検算してログに残す |
| CSVをExcelで開くと文字化け | UTF-8 BOM付きで出力 |

### 再開機能の効果（実測）

```
1回目： ネットワーク要求 42回 / キャッシュ 0回  → 41.0秒
2回目： ネットワーク要求  0回 / キャッシュ42回  →  4.4秒
```

数千件規模になると、途中で失敗したときに最初からやり直せるかどうかが
納期を直接左右します。またテスト時に相手サーバへ無駄なアクセスを繰り返さずに済みます。

## 実行結果（サンプル 一覧2ページ＝40件）

```
取得件数        : 40 件（取得失敗 0 件）
項目の充足率    : 100.0%  (440/440 セル)
UPC重複         : 0 件
ネットワーク要求: 42 回 / キャッシュ利用 0 回
所要時間        : 41.0 秒
```

一覧ページを辿って詳細ページのURLを集め、各詳細ページから11項目を抽出しています。
取得できなかった項目は**出力Excel上で黄色く塗り**、どのセルが欠損かひと目で分かる状態で納品します。

## 取得項目

書名 / カテゴリ / 価格 / 税 / 評価（★を数値化）/ 在庫状態 / 在庫数 / レビュー数 / UPC / 説明抜粋 / URL

## 使い方

```bash
pip install requests beautifulsoup4 openpyxl

python scraper.py                 # 一覧2ページ（40件）
python scraper.py --pages 10      # 件数を増やす
python scraper.py --delay 1.0     # 相手サーバに配慮して間隔を広げる
python scraper.py --no-cache      # キャッシュを使わず取り直す
```

## 出力

| ファイル | 内容 |
|---|---|
| `out/books.csv` | UTF-8 BOM付き。Excelでダブルクリックしても文字化けしない |
| `out/books.xlsx` | 「一覧」（フィルタ・ウィンドウ枠固定つき）＋「カテゴリ別」集計 |
| `out/scrape.log` | 全リクエストの記録と検算結果 |

## 対応できる依頼の形

- 企業リスト・店舗リストの収集 → CSV納品
- 商品価格の定期取得と推移の記録
- 公開データベースからの条件付き抽出
- 収集した結果のスプレッドシート／DBへの連携

ログイン後のページ、JavaScriptで描画されるページ、大量件数の定期実行にも対応可能です。
着手前に対象サイトの規約を確認し、**取得が認められない場合はその旨をお伝えします**。
