# 業務自動化ポートフォリオ

Python による業務自動化ツール3点です。いずれも**そのまま実行して結果を再現できます**。

> 収録データ（氏名・社名・金額・出勤表）はすべて動作確認用に生成した架空のサンプルです。
> 実在の個人・団体とは関係ありません。

---

## 収録作品

### ① [個別指導・シフト自動配置ツール](01_shift_placer/) — 制約充足＋最適化

講師の出勤可否、生徒ごとの受講不可枠、1日の上限コマ数をすべて満たしながら、
「1講師2生徒の座席を埋める」「生徒の空きコマを作らない」という**相反する2条件を同時に成立**させます。

```
必要コマ数 154 → 充足率 100.0% ／ 1対2率 85.7% ／ 生徒の空きコマ 0
```

手作業で十数時間かかる時間割編成が、数秒で終わります。
物理的に入りきらない場合は「誰の何の科目が何コマ不足したか」を明示し、判断材料を返します。

**技術**：MRV法による処理順決定、複合スコアによる貪欲配置、局所改善パス2種、openpyxl

### ② [書式バラバラのExcel一括集計ツール](02_excel_aggregator/) — 帳票の自動読み取り

レイアウトも表記もバラバラな見積書Excelを一括で読み取り、一覧表・取引先別・月別集計に変換します。

```
24ファイル → 抽出成功率 100.0%（144/144項目）／ 明細77行 ／ 処理時間 0.42秒
```

**セル位置を決め打ちしない**のが要点です。ラベル文字列を探索して値を取るため、
項目が動いてもラベルの言い回しが違っても壊れません。
さらに「明細合計≠小計」などの内部矛盾を検算し、疑わしい行を色付きで警告します。

**技術**：ラベル探索型パース、NFKC正規化、表記ゆれの名寄せ、検算ロジック、openpyxl

---

### ③ [Webスクレイピング → CSV/Excel 納品ツール](03_web_scraper/) — 収集の自動化

Webサイトから情報を収集し、業務でそのまま使える形式で納品します。

```
40件取得 → 充足率 100.0%（440/440セル）／ 取得失敗 0件
再実行時：ネットワーク要求 0回（キャッシュ利用）／ 41.0秒 → 4.4秒
```

robots.txt の確認、リクエスト間隔の確保、指数バックオフ再試行、中断からの再開、
取得結果の検算まで実装しています。**相手サーバに負荷をかけない**ことを前提に設計しました。

**技術**：requests / BeautifulSoup、robots.txt準拠、キャッシュによる再開、openpyxl

### ④ [ヒキツギ — 保護者面談レコーダー](04_meeting_recorder/) — 録音から引き継ぎ書まで

iPhone 1台で保護者面談を録音・文字起こしし、AI が講師向けの引き継ぎ書を下書きして
Word（.docx）ファイルとして出力する Web アプリです（単一 HTML・依存ライブラリなし）。

2m 離れた声も拾えるよう、Web Audio API でハイパスフィルタ → コンプレッサー →
可変ゲイン → リミッターの集音強化チェーンを通して録音します。
生成される引き継ぎ書は、音声認識の誤変換を前提に**【事実】【推測】【要確認】を区別**する
プロンプト設計で、そのまま講師に渡せる9章構成です。

**技術**：Web Audio API、MediaRecorder、Web Speech API、WordprocessingML の自前生成（ZIP直書き）、Claude アーティファクト

## 共通して大事にしていること

**1. 数字を出したら、その数字を検算する**
3作品すべてに検算と自己診断を入れています。「動いたように見えるが中身が間違っている」
のが自動化で最も損害の大きい失敗だからです。処理件数・充足率・欠損・矛盾を必ず報告します。

**2. 失敗したときに、何が起きたか分かるようにする**
1件のエラーで全体を止めません。該当箇所を記録して処理を続け、
最後に「どのファイルの何が読めなかったか」を一覧で返します。

**3. 例外を隠さず、判断材料として渡す**
入りきらなかったコマ、金額の合わないファイル、取得できなかった項目は、
黙って握りつぶさずに色付きで可視化します。最終判断は依頼主が行えるようにするためです。

**4. 受け取った人が使い続けられる形にする**
条件はコード内ではなく入力CSV側で表現しています。
仕様変更のたびに開発者に依頼しなくても、依頼主自身で調整できます。

## 動作環境

```bash
pip install openpyxl requests beautifulsoup4
```

Python 3.8以上。Microsoft Excel は不要です（.xlsx を直接読み書きします）。

各フォルダで以下を実行すれば、上記の結果がそのまま再現できます。

```bash
cd 01_shift_placer     && python make_demo_data.py && python placer.py
cd 02_excel_aggregator && python make_demo_data.py && python aggregate.py
cd 03_web_scraper      && python scraper.py --pages 2
```
