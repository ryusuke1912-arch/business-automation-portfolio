## 🏪 ローソン攻略（多用するなら「型」を作る)

### 決済の型: これだけで7〜20%変わる

1. **三菱UFJカード**: ローソン/ローソンストア100が対象店で**最大20%還元**（要エントリー・月5万円利用上限・最大還元には三菱UFJ銀行口座等の条件あり→公式で要確認）。2026年時点の最有力。
2. 持っていなければ **三井住友カード(NL)**: 対象コンビニ7%。ただし**2025年12月からスマホのタッチ決済（Apple Pay/Google Pay）限定**。プラスチックカードのタッチは対象外なので必ずスマホで払う。
3. どちらの場合も**Ponta or dポイントカードを毎回提示**（+0.5〜1%）。Apple WalletにPonta・dポイント両方入れておくとW取りできる。
4. 楽天ポイントカードはローソン非対応。楽天経済圏の人は楽天ペイ払い＋Ponta/d提示で三重取り。

### ポン活（お試し引換券）= ローソン最強の節約手段

- PontaまたはdポイントをローソンアプリまたはLoppiで商品引換券に交換。**1ポイント≒約1.9〜2円の価値**（通常の2倍）。
- **期間・用途限定dポイントも使える** → 失効しがちなポイントの最良の出口。
- 狙い方: **新券は毎週火曜が主軸、朝7:00開始**（14:00/17:00追加、酒類は夕方開始）。人気商品は15分で終了することも。アプリの「予約」機能で最大24時間キープ可能。
- 1引換券につき1人1日1枚。発券後30分有効、期限切れならポイントは約10分で自動返却（損はしない）。
- 毎月1日頃に翌月対象商品の一覧が公式公開される。

### その他のローソン節約テク

- **ハピとくーポン（アプリクーポン）**: 毎週火曜更新。月曜夜〜火曜朝にアプリの「MY BOX」を見る習慣をつける。
- **ハピとく祭「1個買うと1個もらえる」**: 実質半額。2026年夏は7/14〜と7/28〜開催中。
- **アプリでたまるよスタンプ＋Lガチャ**: 税込100円=1スタンプ、20/40個でアイス等の無料券、200個でマチカフェ1杯無料。
- **値下げシール**: 店舗裁量だが 16時/19時/22時前後が目安（まちかど厨房は製造8〜10時間後に半額）。クーポンとの併用可のケースあり。
- **盛りすぎチャレンジ系**は年2〜3回開催（2026年は1月と6月に実施済み）。次回開催時に集中利用。
- **Pontaパス（月548円）**: 毎週55円引×5枚クーポン等で月1,100円相当。ローソンを週5以上使うなら元が取れる。初回30日無料で試す。
- **ローソンPontaプラス（カード）**: 毎月10日・20日の16時以降＋アプリエントリーで6%。まとめ買い日を10日・20日に寄せるなら有効。

### そもそも論（最大の節約）

ローソンは還元を積んでも**スーパーの定価より高い**。「コンビニでしか買えないもの・引換券・半額シール・無料クーポン」に限定し、飲料・冷凍食品・日用品はオーケー/ラ・ムー/マルハチに寄せるだけで月数千円変わる。

## 💳 ポイ活の柱

### ウエル活（毎月20日）— ルール変更済みに注意

- ウエルシアで毎月20日、**WAON POINT**を200pt以上使うと**1.5倍の価値**（実質33%引）。
- ⚠️ **Vポイント（旧Tポイント）の直接利用は2024年8月で終了済み**。今は「Vポイント→WAON POINTに交換→20日に使う」ルート。**交換に日数がかかるので数日前に手続き**。
- 最寄り: ウエルシア神戸中郷店（JR六甲道/阪神石屋川 徒歩10分）。
- 同じ20日はダイエー/グルメシティのイオン系5%OFFデーでもある（30日も）。

### クレカ・コード決済の構成（2026年7月時点）

| 用途 | 推奨 |
|---|---|
| ローソン | 三菱UFJカード（最大20%）or 三井住友NL スマホタッチ（7%）＋Ponta/d提示 |
| スーパー全般 | 楽天カード等の1%カード＋店のポイントカード提示 |
| オーケー | **現金**（会員3%引が現金払いのみ対象のため） |
| 公共料金 | PayPayカードは2026年6月改悪で0.5%に半減→楽天カード等1%維持のカードへ変更 |

- 神戸市対象のPayPay等自治体20%還元は2026年7〜8月は**なし**（8月は加古川市のみ）。「神戸で20%還元」という古い情報に注意。

### 買い物系アプリ

- **トクバイ**（無料）: 近隣スーパーのチラシ横断比較。マルハチ・イズミヤ・オアシス等を登録して特売日で店を使い分ける。
- **TABETE**: フードロス割引。神戸市内の登録店舗数はアプリで要確認。
