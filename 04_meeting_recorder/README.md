# ヒキツギ — 保護者面談レコーダー＆講師引き継ぎ書ジェネレーター

保護者面談を iPhone 1台で録音・文字起こしし、AI が講師向けの「引き継ぎ書」を
下書きして Word（.docx）ファイルとして保存できる、個別指導塾向けの Web アプリです。

単一の HTML ファイル（`index.html`）で完結しており、Claude のアーティファクトとして公開して
iPhone のブラウザ／Claude アプリから利用します。外部ライブラリへの依存はありません。

## 機能

| 画面 | 内容 |
|---|---|
| 録音 | マイク集音を強化して録音（後述）。ライブ文字起こし（日本語）、録音ファイル保存（AAC/mp4） |
| 内容 | 生徒名・学年・科目・面談日などの確定情報の入力と、文字起こしの編集・貼り付け |
| 引き継ぎ | AI が9章構成の引き継ぎ書を生成 → 画面表示・Word (.docx) 保存・コピー |
| 記録 | 面談記録（文字起こし＋引き継ぎ書）の保存と呼び出し |

## 2m 離れた声を拾う工夫

iPhone のマイク入力を Web Audio API で加工してから録音します。

```
マイク → ハイパスフィルタ(85Hz)   … 空調・机の振動などの低音ノイズを除去
      → コンプレッサー(ratio 6)  … 小さい（遠い）声を持ち上げる
      → ゲイン(1〜4倍・可変)     … 集音ブースト（画面のスライダーで調整）
      → リミッター(ratio 20)     … 近い声・物音による音割れを防止
      → MediaRecorder            … AAC(.mp4) で録音
```

- OS 標準のノイズ抑制（noiseSuppression）は**あえて無効化**しています。遠い声を
  ノイズと誤判定して削ってしまうためです。自動ゲイン（autoGainControl）は有効です。
- iPhone は底面マイクを保護者側に向けて、机の中央に置くのが最も効果的です。

## 引き継ぎ書の生成

- 文字起こしと確定情報（生徒名・学年など）を Claude に渡し、9章構成の引き継ぎ書
  （3行サマリー／保護者の要望・懸念／指導依頼 P1〜P3／取り扱い注意事項／要確認事項 など）を生成します。
- 音声認識の誤変換・話者分離なしを前提に、**【事実】【推測】【要確認】を必ず区別**させる
  プロンプト設計です。テンプレート全文は [`handover_template.md`](handover_template.md) を参照。
- 生成結果は画面上で表・見出し付きで表示され、**Word (.docx) ファイルとして保存**できます
  （.docx は ZIP + WordprocessingML を自前生成しており、外部 CDN に依存しません）。

## 動作環境と制限

- iPhone XR / iOS Safari（iOS 14.5 以降）で動作するよう設計しています。
- ライブ文字起こしは Web Speech API（Siri の音声認識）を使用します。環境によっては
  利用できないことがあり、その場合は録音のみ継続し、ボイスメモ等の文字起こしを貼り付けて使えます。
- AI 生成・Word 保存・記録保存は、Claude アプリ内でアーティファクトとして開いたときに
  利用できます。使えない環境では「プロンプトをコピー → Claude に貼り付け」の手動モードに
  自動で切り替わります。
- 面談内容は個人情報です。生成された引き継ぎ書は必ず教室長が確認・修正してから講師に渡す
  運用を前提としています。
